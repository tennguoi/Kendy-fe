Place the invoice font file here as `invoice.ttf`.

The invoice print template loads:

```css
@font-face {
  font-family: 'KendyInvoice';
  src: url('/fonts/invoice.ttf') format('truetype');
}
```

Use a TTF font that supports Vietnamese glyphs, for example Inter, Roboto, Noto Sans, or your licensed brand font.
